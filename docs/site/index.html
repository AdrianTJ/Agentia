Agentia is a reader for what your coding agent wrote.

A fast, minimalist macOS app for opening the Markdown and HTML artifacts agents leave behind — reading them, seeing what changed since the last run, exporting them well.

Download for macOS 13+ Source on GitHub

Free, open source (Apache 2.0), no telemetry leaves your machine. Notarized builds are planned; until then macOS may ask you to approve the app in System Settings → Privacy & Security on first launch.

Why it exists

  • Built for agent output. Not a note-taker, not an IDE. A place to open a generated file and judge it.
  • Live diff. Reopen a document an agent rewrote and the new blocks light up — you see what changed, not the whole page.
  • Contained by design. Agent-written HTML is unreviewed code. Three independent mechanisms keep it off the network and off your clipboard.
  • Honest editing. Markdown is edited in place, byte-for-byte — a save never reformats the document out from under the diff.
  • Fast. Parsing happens in-process with cmark-gfm; the web view receives finished HTML. Double-click to paint is measured, not assumed.

Privacy

Agentia has no accounts, no analytics and no network access of its own. Crash diagnostics Apple sends back through MetricKit stay in ~/Library/Application Support/Agentia/.
